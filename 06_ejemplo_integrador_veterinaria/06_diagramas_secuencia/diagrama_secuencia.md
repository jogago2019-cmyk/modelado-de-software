# 🔄 Diagramas de Secuencia

## 📖 Objetivo

Los diagramas de secuencia modelan la interacción temporal entre:
- actores,
- boundary,
- control,
- y entidades.

El enfoque utilizado sigue el patrón MVC:
- Boundary
- Control
- Entity

basado en la bibliografía de Jim Arlow.

---

## 📌 Diagramas incluidos

- Registrar Cliente
- Registrar Mascota
- Registrar Consulta
- Gestionar Turno
- Registrar Venta
- Registrar Vacuna
- Registrar Internación
- Registrar Cirugía
- Gestionar Productos
- Generar Reportes
