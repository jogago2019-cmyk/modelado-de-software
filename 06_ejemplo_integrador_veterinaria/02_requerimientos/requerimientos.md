# 📋 Requerimientos Funcionales

## RF01 — Registrar Cliente

El sistema deberá permitir registrar clientes con:
- nombre,
- apellido,
- DNI,
- teléfono,
- dirección,
- correo electrónico.

---

## RF02 — Registrar Mascota

El sistema deberá permitir registrar mascotas asociadas a un cliente.

La mascota deberá incluir:
- nombre,
- especie,
- raza,
- edad,
- peso,
- observaciones.

---

## RF03 — Gestionar Turnos

El sistema deberá permitir:
- registrar turnos,
- cancelar turnos,
- reprogramar turnos,
- consultar disponibilidad.

---

## RF04 — Registrar Consulta

El veterinario deberá poder registrar:
- síntomas,
- diagnóstico,
- tratamiento,
- observaciones.

---

## RF05 — Registrar Vacuna

El sistema deberá permitir:
- registrar vacunas,
- calcular próxima dosis,
- consultar historial de vacunación.

---

## RF06 — Registrar Internación

El veterinario deberá poder:
- registrar internaciones,
- registrar evolución diaria,
- indicar medicación,
- registrar alta médica.

---

## RF07 — Registrar Cirugía

El sistema deberá permitir:
- programar cirugías,
- asignar veterinarios,
- registrar resultados.

---

## RF08 — Registrar Servicios de Peluquería

El peluquero deberá poder:
- registrar baño,
- corte,
- limpieza,
- observaciones.

---

## RF09 — Registrar Venta

El cajero deberá poder:
- registrar ventas,
- seleccionar productos,
- calcular importes,
- emitir comprobantes.

---

## RF10 — Gestionar Productos

El administrador deberá poder:
- registrar productos,
- modificar precios,
- actualizar stock,
- consultar disponibilidad.

---

## RF11 — Generar Reportes

El administrador deberá poder generar:
- reportes de ventas,
- reportes de stock,
- reportes de turnos,
- estadísticas generales.

---

# ⚙️ Requerimientos No Funcionales

- El sistema deberá ser intuitivo.
- El acceso deberá realizarse mediante autenticación.
- El sistema deberá mantener historial clínico persistente.
- El sistema deberá permitir múltiples usuarios.
- La información deberá mantenerse actualizada.
- El sistema deberá minimizar errores administrativos.
