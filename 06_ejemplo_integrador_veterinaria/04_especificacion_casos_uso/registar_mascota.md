# 📘 Especificación de Caso de Uso — Registrar Mascota

---

## 🆔 Caso de Uso

| Campo | Descripción |
|---|---|
| Código | CU02 |
| Nombre | Registrar Mascota |
| Objetivo | Registrar una mascota asociada a un cliente |
| Actor Principal | Recepcionista |
| Actores Secundarios | Cliente |
| Prioridad | Alta |
| Precondición | El cliente debe existir |
| Postcondición | Mascota registrada correctamente |


---

## 📖 Escenario Exitoso

| Paso | Acción |
|---|---|
| 1 | La recepcionista busca cliente |
| 2 | El sistema solicita identificación |
| 3 | La recepcionista ingresa DNI |
| 4 | El sistema valida cliente |
| 5 | La recepcionista registra datos mascota |
| 6 | El sistema valida información |
| 7 | El sistema registra mascota |
| 8 | El sistema confirma operación |

---

## 🔀 Escenario Alternativo

| Código | Descripción |
|---|---|
| A1 | Cliente inexistente |
| A2 | Datos incompletos |
